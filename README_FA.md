# پروژه SoLs RolePlay Launcher (Android)

نسخه پایه UI با Kotlin + Jetpack Compose؛ شناسه برنامه `com.sols.roleplay` و سرور تنظیم‌شده `5.57.32.92:7777` است.

## چه چیزهایی پیاده‌سازی شده؟
- صفحه اصلی با تم مشکی/بنفش
- دکمه PLAY (فعلاً نمایشی، چون کلاینت بازی موجود نیست)
- صفحه تنظیمات گرافیکی نمایشی
- صفحه ورود/ثبت‌نام نمایشی (بدون ارسال اطلاعات)
- صفحه ساختار دانلود دیتا (بدون لینک دانلود واقعی)

## چه چیزهایی هنوز لازم است؟
1. کلاینت اندرویدی مجاز و سازگار با پروتکل سرور.
2. فایل‌های بازی از منبع قانونی؛ این پروژه شامل دیتای بازی نیست.
3. میزبان HTTPS برای فایل‌ها و `manifest.json` نسخه‌ها، به‌همراه SHA-256.
4. API امن برای حساب کاربری و API وضعیت سرور.
5. آزمایش واقعی روی دستگاه و ساخت/امضای APK.

## ساخت APK
این یک پروژه Android Studio استاندارد است. باز کردن و ساخت آن معمولاً به محیطی با Android SDK و JDK نیاز دارد. اگر فقط گوشی دارید، می‌توانید فایل ZIP را در یک محیط توسعه ابری سازگار وارد کنید؛ پشتیبانی از ساخت APK با موبایل بسته به سرویس متفاوت است.

پروژه هنوز APK کامپایل‌شده نیست و اتصال واقعی به سرور یا بازی را ادعا نمی‌کند.

## ساخت APK فقط با گوشی (بدون کامپیوتر)

این بسته شامل گردش‌کار GitHub Actions است تا APK در فضای ابری ساخته شود. من از این محیط امکان امضای/کامپایل و تحویل مستقیم APK را ندارم؛ این مراحل با مرورگر گوشی انجام می‌شود:

1. در مرورگر گوشی وارد GitHub شوید یا حساب بسازید.
2. یک مخزن جدید با نام `SoLsLauncher` بسازید.
3. فایل‌های این پوشه را در مخزن بارگذاری کنید؛ ساختار پوشه‌ها را حفظ کنید و پوشه `.github/workflows` نیز باید بارگذاری شود.
4. در مخزن به تب **Actions** بروید و گردش‌کار **Build SoLs Launcher APK** را اجرا کنید (یا پس از push خودکار اجرا می‌شود).
5. وقتی اجرا با علامت سبز تمام شد، اجرای workflow را باز کنید و از بخش **Artifacts** فایل `SoLsLauncher-debug-apk` را دانلود و ZIP آن را استخراج کنید.
6. فایل `app-debug.apk` را باز کنید و نصب را تأیید کنید. ممکن است لازم باشد اجازه نصب از همان مرورگر/فایل‌منیجر را فعال کنید.

اگر build شکست خورد، متن خطا را از بخش Actions بفرستید تا اصلاحش کنیم.

## محدودیت‌های نسخه اولیه

- APK ساخته‌شده نسخه آزمایشی لانچر است، نه خود بازی GTA.
- آدرس `5.57.32.92:7777` فقط تنظیمات سرور است؛ اتصال زنده تا وقتی پروتکل/کلاینت سازگار فراهم نشود تأیید نشده است.
- دانلود دیتا تا وقتی URL HTTPS واقعی و فایل manifest از طرف مدیر سرور تنظیم نشوند، دیتای بازی را دریافت نمی‌کند.
- صفحه ورود نمایشی است و هنوز به سرویس حساب کاربری وصل نیست.
